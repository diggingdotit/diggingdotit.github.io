**digging.it** is a development diary, collection of engineering notes, and set of practical references written while building software.

## What's Here

- **[Diary](/diary/)** — Day-to-day build logs, engineering decisions, gotchas, and distilled takeaways.
- **[Reference](/reference/)** — Concise technical notes, checklists, and curated links to useful articles, videos, tools, and products.
- **[Articles](/articles/)** — Longer-form write-ups on architecture, tooling, and lessons learned.
- **[Projects](/projects/)** — My GitHub projects, both public and in progress.

## How This Site Is Built

This site is built with [Hugo](https://gohugo.io/) and the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme, and deployed to GitHub Pages via a SHA-pinned GitHub Actions pipeline with automated Markdown linting (`markdownlint-cli2`) and weekly Dependabot updates.

The source is public at [github.com/diggingdotit/diggingdotit.github.io](https://github.com/diggingdotit/diggingdotit.github.io).
